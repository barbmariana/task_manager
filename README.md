# 📝 Task Manager API

A simple and powerful Task Manager API built with **Node.js** and **MongoDB**.

This is a **Work In Progress** API project focused on managing tasks via RESTful endpoints. Ideal for learning or extending into a full-stack productivity app.

---

## 🚧 Status

**⏳ In Progress** – Core features are being built. Contributions and feedback are welcome!

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB (Mongoose)**
- **REST API**

---

## 📦 Features (Planned / In Progress)

- [x] Create a task
- [x] Read tasks (single & list)
- [ ] Update a task
- [ ] Delete a task
- [ ] Task completion status
- [ ] Pagination & filtering

## 🧪 Installation & Usage

```bash
# Clone the repo
git clone https://github.com/yourusername/task-manager-api.git
cd task-manager-api

# Install dependencies
npm install

# Add your environment variables
cp .env.example .env

# Run the server
npm run dev
